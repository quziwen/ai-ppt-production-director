# Changelog

## 0.3.6 — 2026-10-12

Unified release on the original `ai-ppt-production-director` repository.

- Continues the public v0.1.0-beta and incorporates the local Patrick v0.3.5 workflow and nine production adapters.
- Keeps all 34 original core modules and Codex, Claude, Cursor and generic entry points.
- Adds a canonical root SKILL.md, task-routed core index, current contracts and a Patrick compatibility entry.
- Separates the general reporting/presentation scope from the optional Patrick profile. Personal SSOT files remain workspace-owned and are not distributed.
- Includes the HTML visual editor, shared Deck IR, native PPTX exporter, chart preview, safe output handling and package inspector.
- Includes v0.3.5 delivery-standard confirmation, requirement-to-evidence mapping and defect/change/preference feedback classification.
- Uses immutable versioned packages; existing local installations are backed up before replacement.

This release consolidates distribution and entry points. It does not claim new E3/H3, whole-deck, cross-Office or cross-agent production acceptance. See [TESTING.md](TESTING.md) and [DELIVERY.md](DELIVERY.md).

## Working editions 0.2–0.3.5

Local Patrick working editions developed editability, visual co-design, chart rendering, validation and evidence-linked delivery. They were not published as intermediate releases in this repository. Version 0.3.6 reunites that work with the existing public project; it does not create a second product.

## 0.1.0-beta — 2026-07-17

Initial public idea-to-deck release, with platform-neutral core, host adapters, original recipes, review and licensing gates. The original release and assets are retained.
