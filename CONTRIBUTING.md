# Contributing

Contributions are welcome when they improve the workflow, adapters, examples, QA checks, or original template recipes.

## Contribution Rules

Do:

- improve platform-neutral workflow clarity;
- add original template recipes;
- add fictional examples;
- improve adapter instructions;
- improve QA and licensing checks;
- keep instructions concise and reusable.

Do not:

- submit private business decks;
- submit company logos, internal screenshots, videos, fonts, or templates;
- submit third-party template files;
- submit copied commercial layouts;
- submit real customer cases or internal metrics;
- submit credentials, local paths, or conversation transcripts.

## Pull Request Checklist

Before opening a pull request:

- confirm all examples are fictional or sanitized;
- confirm no binary deck, video, or private media files are included;
- confirm new template assets are original and redistributable;
- update `README.md` if the public interface changes;
- update `core/qa-checklist.md` if a new risk is introduced;
- validate any changed Codex `SKILL.md` file when possible.

## Style

- Use clear English for public repository content.
- Prefer short, operational instructions.
- Avoid tool-specific claims unless the adapter is explicitly tool-specific.
- Keep private implementation history out of public docs.
