# cost-expense-control-v0.1

此包包含已选版式、两种配色的 PPTX 和逐页图片，以及合成数据与样张构建脚本。主题与版式分别选择。

- 选版式：patterns.json；选配色：themes.json。
- 样张：samples/shenzhen.pptx 及另一参考主题。预览位于 previews/。
- 原生文本、形状、表格及适用图表可继续制作；图表数据刷新与完整制作验收按当前项目执行。FA 瀑布图为形状和文字，需随数据重新计算。
- build.cjs 需要当地 Node.js 与 pptxgenjs；输入是合成演示数据，输出目录必须新建。不要把合成数字和原因带进真实财务汇报。
- PRIOR_QA.md 是历史检查记录；其中旧机器路径和旧状态不作为当前运行规则。
- 当前风格规范仍在任务工作区动态读取。本模板包为可选素材，不是长期风格规范。
