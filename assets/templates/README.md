# Template Assets

This folder contains original seed recipes and optional user-selectable asset collections.

The standard package contains original seeds. Approved optional collections live under `user-collections/` and are included with `package-codex.ps1 -IncludeUserTemplates`. The v0.3.7 templates-included release publishes the selected Patrick collection: 23 native patterns, 8 HTML layouts and 9 visual references; see [the selection guide](../../references/USER_TEMPLATE_SET.md).

Each collection has a catalog, local previews and materialization resources. Current workspace rules remain authoritative; these adjustable assets do not define a second style system.
