# Security Policy

## Supported Versions

The latest public release is supported.

Older examples and adapters may be revised or removed if they create privacy, licensing, or unsafe-use risk.

## Reporting Issues

Please report:

- accidental inclusion of private or sensitive content;
- possible third-party licensing issues;
- leaked local paths, credentials, tokens, or account identifiers;
- unsafe adapter instructions;
- prompt patterns that encourage copying private or copyrighted material.

Use GitHub Issues for non-sensitive reports.

For sensitive reports, use GitHub private vulnerability reporting if it is enabled on the repository. If it is not enabled, contact the repository maintainer through the public profile contact method.

## Maintainer Response

Maintainers should:

- remove or redact sensitive content quickly;
- rotate any exposed credentials outside this repository if needed;
- document the fix in a release note when appropriate;
- avoid preserving private content in public issue comments.
