# Capability Levels

Use capability levels to make output quality more consistent across agents, models, and tools.

## Level 1. Thinking Mode

Use when:

- the user has a vague idea, project experience, rough theme, or scattered notes;
- the audience, thesis, or angle is unclear;
- producing slides immediately would create generic content.

Deliver:

- clarified audience and objective;
- thesis options;
- core arguments;
- missing evidence;
- next questions.

Do not deliver:

- a full deck;
- fake facts;
- polished visual claims without source material.

## Level 2. Blueprint Mode

Use when:

- the user wants a plan, outline, page map, script, or production plan;
- source material exists but is not yet converted into slides;
- tool access is uncertain.

Deliver:

- storyline options;
- recommended storyline;
- page argument map;
- visual recipe;
- build route;
- QA plan.

## Level 3. Production Mode

Use when:

- the storyline and page map are stable;
- the user asks for actual PPTX, HTML, PDF, or source files;
- the current environment has suitable tools.

Deliver:

- generated files;
- source of truth where applicable;
- QA notes;
- known limitations.

Never claim production succeeded without checking files or tool outputs.

## Level 4. Studio Mode

Use when:

- the deck is board, executive, investor, client, classroom, public, or conference-facing;
- multiple source files or media assets are involved;
- visuals or editability matter;
- licensing or confidentiality risk exists.

Deliver:

- staged approvals;
- preview budget decision;
- representative sample, section preview, or full HTML preview when justified;
- contact sheet or visual review when possible;
- editability classification;
- delivery package checklist.

## Mode Selection Rule

Default to the lowest sufficient mode.

Move upward only when the user asks for production or the deck risk requires stronger controls. Move downward when tools are missing, time is short, or the user explicitly wants only thinking or planning.
