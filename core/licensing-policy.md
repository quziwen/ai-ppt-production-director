# Licensing Policy

This repository is designed for public release.

## Current approved collection

Version 0.3.7 includes the maintainer-approved `assets/templates/user-collections/patrick-20261014/` set: reconstructed financial patterns with synthetic data, eight imported HTML layouts/previews, and nine public visual references. Keep their cataloged source URLs and provenance. This collection-specific publication does not authorize adding private uploads or other external templates, and does not claim that this project's license transfers ownership of imported sources. The lightweight standard package omits this collection.

## Allowed

- Original workflow documentation.
- Original template recipes.
- Original seed templates created for this repository.
- Links to external inspiration sources.
- Sanitized fictional examples.
- User-provided assets when the user confirms rights and the target use permits inclusion.
- User-provided PPT/PPTX templates for private project use when the user confirms ownership, license, or authorization.

## Not Allowed

- Private business decks.
- Internal screenshots, videos, logos, fonts, or templates.
- Unapproved third-party template files from Canva, Slidesgo, marketplace sites, or similar sources.
- Private user-uploaded templates committed into this public repository without specific publication authorization.
- Decompiled or reconstructed commercial templates.
- Conversation transcripts containing private context.
- Local file paths, credentials, account names, or private workspace details.

## External Template References

External template sites may be referenced as inspiration or linked resources.

Outside an explicitly approved and cataloged collection, do not copy:

- template files;
- slide screenshots;
- proprietary layouts;
- preview images;
- icon sets;
- fonts without redistribution rights.

## Public Examples

Examples must be fictional, generic, or sanitized.

Do not include identifiable:

- companies;
- customers;
- people;
- real metrics;
- project names;
- internal systems;
- private decisions.

## Review Rule

If there is doubt, treat the content as not publishable until the user confirms the right to include it.

## User-Provided Templates

User-provided PPT/PPTX templates may be used in a private project only after rights and confidentiality are classified.

Allowed private uses:

- build from an owned or licensed template;
- extract style tokens;
- extract slide masters and page patterns when tools allow;
- use as inspiration-only when rights are unclear.

Not allowed public uses:

- commit the uploaded template file;
- commit screenshots from the uploaded deck;
- redistribute extracted fonts, icons, images, or brand assets;
- clone a commercial template as a public seed template.
