# Visual QA Rubric

Use this rubric to judge whether sample slides or a full deck look professional, balanced, and consistent.

This is not a design-taste replacement. It is a repeatable QA layer for AI-generated decks.

## When To Run

Run on:

- 1-2 sample slides before bulk production;
- contact sheet after full build;
- revised slides after visual feedback;
- decks that feel plain, unbalanced, crowded, or generic.

## Score Scale

Use 1-5 for each dimension.

| Score | Meaning |
|---|---|
| 1 | broken or unusable |
| 2 | rough, generic, or visibly unbalanced |
| 3 | acceptable but not polished |
| 4 | professional and usable |
| 5 | strong, distinctive, and publication-ready |

## Dimensions

| Dimension | What To Check |
|---|---|
| art direction | one recognizable visual world, not random styling |
| hierarchy | viewer knows what to read first, second, third |
| layout balance | weight, alignment, and spacing feel intentional |
| density fit | text volume matches audience and scene |
| page rhythm | deck has variety without random jumps |
| diagram quality | diagrams explain the point instead of decorating |
| chart/table readability | numbers, labels, and units can be read and interpreted |
| asset consistency | icons/images/lines/callouts share one style |
| editability fit | visual choices match the promised editability level |
| business clarity | the slide advances the argument, not just visual polish |

## Pass Thresholds

For low-risk internal drafts:

- average score at least 3.0;
- no dimension below 2.

For executive, board, client, classroom, or external decks:

- average score at least 4.0 on sample slides;
- no dimension below 3;
- layout balance, hierarchy, density fit, and business clarity must be at least 4.

For visually ambitious public decks:

- average score at least 4.2;
- art direction, page rhythm, and diagram quality must be at least 4.

## Contact Sheet Review

When slides are rendered to images, inspect the contact sheet for:

- repeated layout monotony;
- random style shifts;
- pages that are too dense or too empty;
- title drift;
- inconsistent margins;
- uneven visual weight;
- color misuse;
- slides that do not belong to the same deck.

## Output Template

```text
Visual QA score:
| Dimension | Score | Issue | Fix |

Pass/fail:
Required fixes:
Optional improvements:
Slides needing redesign:
```

## Fix Routing

| Problem | Route |
|---|---|
| hierarchy weak | rewrite title, resize content blocks, reduce equal-weight elements |
| layout unbalanced | apply layout grammar and grid |
| too much text | use content density control |
| too empty | add diagram/proof point or merge slide |
| generic visual | revise recipe, motif, asset system |
| inconsistent assets | normalize icon/image/callout rules |
| bad editability fit | reclassify page route or simplify visual layer |
