# Template Discovery Guide

Use this guide when the user wants external visual inspiration but does not already have a preferred PPT, screenshot, or template.

The goal is to help the user find a direction safely, not to import third-party templates into this public repository.

## Product Rule

Recommend style cards first. Recommend external template websites only when the user wants more inspiration or a closer visual match.

Do not require the user to search websites before producing a useful plan.

## What To Ask The User To Bring Back

The user can provide any of:

- a link to a template or gallery page;
- a screenshot of pages they like;
- a downloaded PPTX they are licensed to use;
- a short note: what they like and dislike;
- 2-3 page numbers from a reference deck.

## Safe Use Modes

| User Provides | Safe Use |
|---|---|
| public link | inspect broad style only; do not copy files or preview images |
| screenshot | extract abstract layout and visual language; do not publish it |
| licensed PPTX | classify rights; use privately if allowed |
| brand template | use only within the user's authorized project |
| unclear template | inspiration-only; create original recipe |

## Suggested Discovery Sources

Use these as examples of where users may look for inspiration. Do not bundle their files.

| Source Type | Examples | Notes |
|---|---|---|
| official templates | Microsoft PowerPoint templates, Google Slides templates | useful for common editable layouts |
| design platforms | Canva, Adobe Express, Figma Community | strong inspiration, but licenses vary |
| presentation template sites | Slidesgo, SlideModel, Envato Elements, Pitch, Beautiful.ai galleries | useful for browsing style; check license before reuse |
| company examples | public investor decks, conference talks, product launches | good for structure and tone; avoid copying brand assets |
| generated deck benchmarks | NotebookLM, Gamma, Tome-like outputs | useful for visual benchmark; often low editability |

## License Reminder

Before using an external template file, confirm:

- who owns it;
- whether the user has a license;
- whether commercial/internal use is allowed;
- whether redistribution is prohibited;
- whether fonts, icons, photos, and illustrations are separately licensed;
- whether the file contains private or brand-controlled assets.

## Agent Response Pattern

```text
You do not need a template to start. I can recommend 2-3 original style directions now.

If you want closer visual inspiration, you can browse template sites and send back:
- one link or screenshot;
- what you like about it;
- whether you have rights to use the actual PPTX.

I will not copy or redistribute third-party template files. I will either use it privately if rights are clear, or convert it into an original style recipe.
```
